# قَريض v2.1.3

> بُني ملفُّ APK في هذا الإصدار باسم حزمةٍ خاطئ (`com.example.qarid`)، فيُثبَّت تطبيقًا ثانيًا بجانب قريض ولا يحدّثه. ثبِّت [v2.1.4](https://github.com/ZahakJ/qarid/releases/tag/v2.1.4) بدلَه.

- زرُّ «شارِك نصّ القصيدة» يرسل أبياتَ القصيدة كلَّها ورابطَها تحتها. تجده في شريط القصيدة، وعلى الهاتف في ورقة «أأ» وفي وضع القراءة.
- «شارِك القصيدة» و«شارِك نصّ القصيدة» كلاهما يفتح ورقةَ المشاركة: ورقةَ النظام في التطبيق، وورقةَ المتصفّح حيث يكون له واحدة، والحافظةَ فيما سوى ذلك. وكان «شارِك القصيدة» في المتصفّح يذهب إلى الحافظة مباشرةً.

---

> This APK was built with the wrong package name (`com.example.qarid`), so it
> installs as a second app beside قريض instead of updating it. Install
> [v2.1.4](https://github.com/ZahakJ/qarid/releases/tag/v2.1.4) instead.

- «شارِك نصّ القصيدة» sends a whole قصيدة, every بيت with the link under it,
  from the poem toolbar, from the phone's «أأ» sheet, and from reading mode.
- Both poem shares now open a share sheet: the native one in the app, the
  browser's where it has one, and the clipboard otherwise. In a browser
  «شارِك القصيدة» used to go straight to the clipboard.

# قَريض v2.1.4

- **أندرويد: التطبيقُ يُحدَّثُ في مكانِه من جديد.** نسختا 2.1.2 و2.1.3 بُنيتا
  باسمِ حزمةٍ خاطئ (`com.example.qarid`)، فثُبِّتتا تطبيقًا ثانيًا بجانبِ قريض
  بدلَ أن تُحدِّثاه. أمّا 2.1.4 فبالاسمِ الصحيح، تُثبَّتُ فوقَ 2.1.1 وتُبقي
  دخولَك وبياناتِك. ولا تُبنى نسخةُ إصدارٍ بعدَ اليومِ بالاسمِ المؤقّت.

- Android: the 2.1.2 and 2.1.3 builds carried the wrong package name
  (`com.example.qarid`), so they installed as a second app beside قريض instead
  of updating it. 2.1.4 carries the real package name again and updates 2.1.1 in
  place; a release build now fails under the placeholder package name.

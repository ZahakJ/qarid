القاعدة

يُلقي الحاسوبُ بيتًا، ويُجاب ببيتٍ آخرَ من الديوان يبدأ برويِّ الأوّل: الحرفِ الذي تُبنى عليه القافية، لا آخرِ حرفٍ مكتوب. الحكمُ على مذهب القدماء، ولا يُقبل القريب.

ما فيه

القراءة

تصفّحٌ بالعصر والبحر والغرض والرويّ. ديوانُ كلِّ شاعر. والقصيدةُ صفحةً كما تُطبع، أو في وضع قراءةٍ تنزوي فيه الأدواتُ كلُّها.

البحث

FTS5 على ثلاثة ملايين بيت، بمُطبِّعٍ عربيٍّ واحد: يُصيب النصَّ بتشكيلٍ وبغيره، وبأيّ ألف.

المساجلة

ضدّ الديوان، بعدٍّ ووقت، وتُضيَّق بعصرٍ أو بحرٍ أو شاعر. أو ضدّ صديقٍ في غرفة، والحكمُ عند الخادم لا عند اللاعب.

الحفظ

المختاراتُ قائمةٌ في المتصفّح بلا حساب. والدواوينُ رفوفٌ مُسمّاةٌ مرتَّبةٌ على حساب، تُشارَك وتُلعب فيها المساجلة.

التحفيظ

تمرينٌ على القصيدة حتى تثبت، وعدٌّ لما صار يُجاب عليه من الحروف.

على الهاتف

بناءُ أندرويد من المصدر نفسه، أصولُه محزومةٌ فيفتح بلا شبكة.

صور

على الهاتف، من بناءٍ حقيقيٍّ لا من نافذةٍ مضيَّقة.

المتن

الأبياتُ من arbml/ashaar. تُدخَل في مِعلَمٍ واحدٍ من SQLite للقراءة فقط، ولا يُعاد نشرُها: يُبنى المِعلَم محلّيًّا في نحو ثلاث دقائق.

المقروء254,630 قصيدة
المحذوف15,891 قصيدة مكرّرة، و6 قصائد بلا أبيات
الباقي238,733 قصيدة · 3,369,701 بيتًا · 6,941 شاعرًا
الصالح للمساجلة1,713,459 بيتًا — له شطران ورويٌّ يُستخرج
بلا بحر39.8% من القصائد

والمتنُ مكشوطٌ ويظهر ذلك: عناوينُ كثيرةٌ هي المطلعُ منزوعَ التشكيل، وأبياتٌ فقدت شطرًا في الطريق. يُتعامل مع ذلك ولا يُدّعى خلافُه، وما يُحسن أن يُعرف قبل «إصلاحه» مدوَّنٌ في CLAUDE.md.

التشغيل

حزمةُ npm واحدة، وثلاثُ تبعيّاتٍ للخادم، ولا بناءَ له: TypeScript يُشغَّل مباشرةً على Node 24 فما فوق.

git clone https://github.com/ZahakJ/qarid && cd qarid
npm install
cp .env.example .env          # ثم يُضبط PUBLIC_ORIGIN

# ملفّات arbml/ashaar (parquet) في data/raw/ ثم:
npm run ingest                # نحو 3 دقائق، 700 م.ب ذروةً، 1.6 غ.ب ناتجًا

npm run dev:server & npm run dev

وبلا متن: npm run ingest:fixture يبني عيّنةً من ملفّات الاختبار في ثوانٍ، ويعمل عليها كلُّ شيء.

في الإنتاج يربط الخادمُ على loopback وحده ويقدّم العميلَ المبنيَّ بنفسه؛ يُوضع أمامه وكيلٌ أو نفقٌ للـTLS. وdeploy/qarid.service وحدةُ systemd للمستخدم، بلا جذر.

وحدُّ الإنجاز أربعةٌ كلُّها خضراء:

npm run typecheck && npm test && npm run build && npm run smoke

البناء

المتنمِعلَمُ SQLite واحدٌ للقراءة فقط، على مرورَين، بفهرس FTS5. يُفتح readOnly فتُرمى الكتابةُ العارضةُ بدل أن تُفسده.
الخادمHono على node:sqlite. بلا بناء. التطبيقُ بلا استماع، فتُقاد الاختباراتُ داخل العمليّة.
العميلVite وReact، توجيهٌ بالكسر، من اليمين إلى اليسار. أميري للشعر، وعارف رقعة للعناوين.
المشتركمُطبِّعٌ عربيٌّ واحد، ومنسِّقُ أعدادٍ واحد، ومولِّدٌ عشوائيٌّ مبذور، ومخطّطاتُ zod مرجعًا لكلِّ ما على السلك.
الاختبار1,583 اختبارًا، ومشيٌ يشغّل الخادمَ الحقيقيَّ على 29 مسارًا بعرضَي الحاسوب والهاتف، ويفشل على أيّ خطأٍ في السجلّ.
